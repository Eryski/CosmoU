cosmou-ambient.wav is an original ambient loop made for CosmoU. It ships with every build.
To use your own music privately, click "Music folder" in CosmoU's Settings and put one audio
file (.mp3, .ogg, .wav, .m4a or .flac) there. A file in that folder is played instead of the bundled loop.
Do not put copyrighted music in this assets/music folder if you share or publish builds of CosmoU.

themes/ holds one original loop per theme: Liquid Glass (Glass Lagoon), Wii U (Home Sweet Menu), Classic Wii (Channel Calm),
Plaza (Buddy Parade), Switch (Quiet Home), Switch 2 (Next Level Lounge), DS (Dual Screen Days), DSi (Camera Café),
3DS (Pocket Sunshine), N64 (Cartridge Night), GameCube (Indigo Cube), Game Boy (Green Screen), Virtual Boy (Red Horizon),
SNES (16-Bit Meadow), NES (8-Bit Morning). All were synthesized for CosmoU and play while no own music file is chosen.
On install and on every update CosmoU copies them to the music folder (music/themes). Replace a file there with
your own under the same name (e.g. plaza.ogg) to change a theme's tune; CosmoU never overwrites a file you replaced.
